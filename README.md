# VIP Kanspel · Windrose Giants Antwerp vs Vilpas Vikings (di 17/11/2026)

Exclusief voor VIP-gasten. Zij wagen hun kans vóór de wedstrijd: (1) wie scoort de eerste driepunter van de Giants en (2) hoeveel punten hebben de Giants na het eerste kwart? Bij de start van de wedstrijd sluit de stemming. Eén kans per persoon (per toestel én per GSM-nummer). De winnaar wordt bekendgemaakt tijdens de VIP-talk na de wedstrijd en ontvangt daar een fles champagne.

- `index.html` – kanspelpagina (QR-code), Nederlands of Engels
- `admin.html` – beheer: stemming sluiten/openen, uitslagen invullen, winnaars, CSV, reset. Installeerbaar als app (admin.webmanifest).
- Spelersfoto's: antwerpgiants.be/roster (seizoen 2026-2027), bijgesneden.

Gegevens staan in Firebase Realtime Database (project giants-veiling, pad `vipgok1711`), alleen leesbaar voor de beheerder. Er staan geen persoonsgegevens of sleutels in deze repo.
